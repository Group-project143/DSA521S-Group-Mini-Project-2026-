# DSA521S Group Mini-Project 2026

## NUST – Data Structures and Algorithms 1

This repository contains the implementation and documentation for the **DSA521S Data Structures and Algorithms 1 Group Mini-Project 2026**.

The project demonstrates the practical implementation and application of fundamental data structures and sorting algorithms. The individual project tasks were also integrated into a menu-driven **NUST Service Centre System**.

## Project Components

### Part A – Data Structures

Part A focuses on the implementation and application of different data structures.

The tasks include:

- **A1 – Queue**
  - Student waiting queue
  - Enqueue operation
  - Dequeue operation
  - Peek operation
  - Display queue
  - FIFO principle

- **A2 – Singly Linked List**
  - Student service records
  - Insert records
  - Search records
  - Delete records
  - Display records

- **A3 – Stack**
  - Stack operations
  - Postfix expression evaluation
  - Push and pop operations

- **A4 – Arrays and Statistics**
  - Processing student service-time data
  - Total service time
  - Average service time
  - Highest service time
  - Lowest service time
  - Services taking longer than 10 minutes

### Part B – Sorting Algorithms

Part B demonstrates four sorting algorithms using service-time data.

The algorithms implemented are:

- **B1 – Selection Sort**
- **B2 – Insertion Sort**
- **B3 – Merge Sort**
- **B4 – Quick Sort**

The sorting algorithms arrange the service-time values in ascending order.

Example input:

`17, 5, 23, 8, 14, 3, 11, 20, 6, 9`

Sorted result:

`3, 5, 6, 8, 9, 11, 14, 17, 20, 23`

### Part C – Sorting Algorithm Comparison

Part C compares the performance of the sorting algorithms using different input sizes.

The comparison considers:

- Number of comparisons
- Number of swaps or shifts
- Execution time
- Behaviour on different input sizes
- Behaviour on almost-sorted data

### Part D – Integrated Service Centre System

Part D combines the different components into a single menu-driven **NUST Service Centre System** implemented in C.

The system provides the following options:

1. Add Student to Queue
2. Serve Next Student
3. View Waiting Queue
4. Add Service Record
5. Search Service Record
6. Delete Service Record
7. Display All Service Records
8. View Daily Statistics
9. Sort Service Times
0. Exit

The integrated program demonstrates the use of:

- Queues
- Singly linked lists
- Arrays
- Searching
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Dynamic memory allocation
- Functions
- Loops
- Conditional statements
- Recursion

### Part E – Pseudocode

Part E contains pseudocode for the major data structures and algorithms implemented throughout the project.

This includes pseudocode for:

- Queue operations
- Linked-list operations
- Stack operations
- Array processing
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

## Programming Languages

The project contains implementations developed using:

- **C**
- **Java**

The final integrated NUST Service Centre System is implemented in **C**.

## Running the Integrated Program

The main integrated program is:

`PartD_ServiceCentre.c`

Compile it using GCC:

```bash
gcc PartD_ServiceCentre.c -o PartD_ServiceCentre
```

Run the program:

### Windows

```bash
PartD_ServiceCentre.exe
```

### Linux/macOS

```bash
./PartD_ServiceCentre
```

The program will display the NUST Service Centre menu, where the user can select the required operation.
